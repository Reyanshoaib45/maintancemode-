Forgot-password: missing table `password_reset_tokens`

On /forgot-password SQL error: SQLSTATE[42S02]: Table 'pos.password_reset_tokens' doesn't exist when trying to delete token.

Database Authentication
High
  1. Check migrations for password_resets vs password_reset_tokens.
  2. Run php artisan migrate or adjust config auth.passwords table name.
  3. Search for custom code deleting from password_reset_tokens and update.

Quicksection route logs out admin

After login as admin, navigating to Quicksection immediately logs the user out.

Possible causes: middleware redirect, session guard mismatch, or CSRF/session domain problem.

Routing Authentication
High
  • Inspect Quicksection controller for Auth::logout() or redirect()->guest() calls.
  • Check session lifetime, domain, and cookie settings in config/session.php.
  • Verify middleware stack — maybe route uses a different guard.
